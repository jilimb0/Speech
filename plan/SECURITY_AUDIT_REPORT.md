## 1. Обнаруженные и устраненные уязвимости

### [P2] Обход авторизации в middleware + Валидация аудиофайлов — УСТРАНЕНО
* **Файлы:** `apps/api/src/middleware/tma-auth.ts`, `apps/bot/src/handlers/voice.ts`
* **Описание риска:**
  Условие `initData === 'dev'` позволяло полностью обходить TMA-авторизацию при нестрогой конфигурации окружения. Отсутствовала проверка magic bytes для входящих голосовых сообщений, что создавало риск загрузки вредоносных бинарных файлов.
* **Реализованное решение:**
  - В `apps/api/src/middleware/tma-auth.ts` внедрен строгий запрет: при `NODE_ENV === 'production'` dev bypass заблокирован безусловно.
  - Публичный доступ оставлен только для health-эндпоинтов (`/health`, `/api/health`).
  - В обработчиках голоса добавлена валидация сигнатур (magic bytes): OGG (`OggS`), WAV (`RIFF`), MP3 (`ID3`/`\xFF\xFB`), MP4/M4A (`ftyp`), FLAC (`fLaC`), а также лимит размера файла 20 МБ.
